# LightTab 1.24.0

Store / unpacked zip: `lighttab-1.24.0-chrome.zip` (attach on the GitHub Release).

## Highlights
- Calendar page: week / month / year, wallpaper-blended type, day agenda, local events, ICS subscribe
- Weather on the clock; second timezone by city; homepage verse
- About tab with GitHub + WeChat / Alipay
- Settings cleanup; avatar upload from the profile menu

## Upgrade
Chrome Web Store users on 1.23.5 receive 1.24.0 automatically after this build is published to the **same** listing. Unpacked installs do not auto-update.
