## 回归命令

- `node scripts/smoke.cjs`
- `playwright test -c tests/e2e/playwright.config.js`
- `node scripts/check-launcher-extension.cjs`（隔离 MV3，模拟目标页；不代表真实服务验证）
- `node scripts/check-extension.cjs`
- `node scripts/package-release.cjs`

运行浏览器测试需已安装 Playwright。真实服务尚受登录状态、地区可用性、桌面应用环境限制，上述 1–4 不能当作全面通过。
