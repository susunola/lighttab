LightTab — Privacy Policy

Last updated: 2026-09-06

Local-first by default

LightTab stores shortcuts, display name, to-dos, wallpapers, and AI prompt templates in the local browser via chrome.storage.local. It contains no analytics or advertising trackers. Optional cloud sync uploads the selected data to the sync service.

Search suggestions are enabled by default and send typed queries directly to the selected search provider. Other network activity is described below. Local storage does not mean that every feature operates offline.

Permissions

storage — used solely for local persistence as described above. It does not transmit data anywhere on its own.

bookmarks (optional) — requested when the user imports bookmarks. Imported shortcuts are retained locally and are included in cloud sync if enabled.

tabs (optional) — requested for "Add current tab" to read its title and URL. Saved shortcuts follow the same storage and sync behavior.

The manifest also declares access to the Baidu, Google and Bing suggestion endpoints and content-script matches for the supported AI sites.

Search suggestions and destinations

Suggestions send typed queries to suggestion.baidu.com, suggestqueries.google.com or api.bing.com, depending on the selected engine. Disable suggestions in Settings → General to keep typing local until you launch a search. Opening a search, website or AI tool contacts the selected service under that service's own policies.

Optional cloud sync

LightTab offers an optional multi-device sync. It is completely off until the user registers an account and logs in. Once enabled:

  • Local data (shortcuts, display name, to-dos, wallpapers, prompt templates, and settings) is synced to the user's own account on lighttab.atomwangnus.com.
  • The client sends sign-in credentials and synchronization data over HTTPS. Sync payloads are not end-to-end encrypted by the extension.
  • No data is shared across accounts, and the server uses the data only to perform synchronization.

Logging out attempts to revoke the current token and stops cloud sync on this browser; if offline, local sign-out does not guarantee server revocation. Logging out but does not delete existing server data or disable other online features. The account-deletion feature requires the current password and deletes the account and associated records from the active service database. Local browser data is retained. Existing server backups may retain earlier data until removed under the operator’s backup retention process. First-login differences and revision conflicts pause the affected document until you choose the device or cloud copy.

Before sign-in sync, cloud replacement or backup restoration, LightTab saves a local recovery snapshot. The latest three snapshots include the five synced data documents and schema version, but no sign-in credentials or search history. A displaced cloud conflict is saved with the remaining local documents, not as a complete cloud-account snapshot. Backups are not uploaded. You can download, restore or delete them in Settings → Sync; clearing browser data also removes them. Restoration signs out of cloud sync and leaves cloud data unchanged. If saving a backup fails, replacement stops.

Wallpaper library (optional)

Opening the wallpaper tab contacts lighttab.atomwangnus.com to discover available sources and fetch library metadata. Selecting or rotating online wallpapers may fetch image URLs from their hosts. Enabled daily rotation can refresh the library automatically. Available sources may include Bing, Wallhaven and Unsplash.

Wallpaper images and their titles/copyright notices belong to their respective rights holders; LightTab displays the attribution provided by the source and stores the chosen image only as the user's local background preference.

Daily movies

When the daily movie widget is enabled, LightTab requests the public hot-movie list from movie.douban.com and caches it locally for 24 hours. Posters load from doubanio.com without a referrer. These requests expose normal network information such as your IP address to the provider; no account, search history or shortcut data is sent. Cached and bundled movies are used when requests fail.

Content script

The extension injects a content script on supported pages of www.doubao.com, www.dola.com and chatgpt.com. On a prompt launch it reads a temporary local prompt entry, locates the page's input and send controls, fills the prompt and attempts to submit it. Submission sends your prompt to the selected AI provider. If automatic entry fails, the extension attempts to copy the prompt and displays a notice. It does not collect your conversation history or cookies.

Weather and local app detection

Weather is off by default. When enabled, city lookup and forecasts contact geocoding-api.open-meteo.com and api.open-meteo.com. Forecasts are cached locally.

At startup, LightTab probes 127.0.0.1 ports 18488–18490 to detect WorkBuddy on this computer. These requests stay on the local computer. Choosing WorkBuddy can pass a prompt to the desktop app via its deep link.

Contact

For any privacy questions, please open an issue in the project repository. Do not post passwords, private prompts or other sensitive information in public issues.
