LightTab — Privacy Policy

Last updated: 2026-09-03

Zero data collection

LightTab does not collect, transmit, sell, or share any user data. All user data — shortcuts, display name, to-dos, wallpapers, and AI prompt templates — is stored exclusively in the user's local browser via chrome.storage.local.

No network requests are made by the extension. There is no analytics, no tracking, and no account system.

Permissions

storage — used solely for the local persistence described above. It does not sync to any server and does not transmit data anywhere.

bookmarks (optional) — requested only when the user explicitly clicks "Import from bookmarks" in settings. It is used once to read the local bookmark tree, and the data is not retained or transmitted.

Content script

The extension injects a content script on doubao.com and chatgpt.com. When the user actively launches an AI prompt template, this script reads an extension-written local entry (lt.pending.<nonce>), fills it into the chat input, and submits it. It does not read, store, or transmit any page content, chat history, cookies, or other user data, and it makes no network requests.
