LightTab — Privacy Policy

Last updated: 2026-09-03

Local-first by default

LightTab does not collect, sell, or share any user data. By default, all user data — shortcuts, display name, to-dos, wallpapers, and AI prompt templates — is stored exclusively in the user's local browser via chrome.storage.local. There is no analytics and no tracking.

No network requests are made unless the user actively opts in to an optional online feature (cloud sync, or the wallpaper library), as described below.

Permissions

storage — used solely for local persistence as described above. It does not transmit data anywhere on its own.

bookmarks (optional) — requested only when the user explicitly clicks "Import from bookmarks" in settings. It is used once to read the local bookmark tree; the data is not retained or transmitted.

Optional cloud sync

LightTab offers an optional multi-device sync. It is completely off until the user registers an account and logs in. Once enabled:

  • Local data (shortcuts, display name, to-dos, wallpapers, prompt templates, and settings) is synced to the user's own account on lighttab.atomwangnus.com.
  • Passwords are stored only as bcrypt hashes — never in plaintext. All traffic is encrypted over HTTPS.
  • No data is shared across accounts, and the server uses the data only to perform synchronization.

The user can log out at any time. After logging out, the extension makes no further network requests and behaves exactly like the fully local version.

Wallpaper library (optional)

The settings → wallpaper tab offers an optional "Bing daily wallpaper" library. Only when the user clicks "Fetch latest" does the extension contact lighttab.atomwangnus.com to retrieve wallpaper metadata and images (which originate from Bing). No request is made otherwise.

Wallpaper images and their titles/copyright notices belong to their respective rights holders; LightTab displays the attribution provided by the source and stores the chosen image only as the user's local background preference.

Content script

The extension injects a content script on doubao.com and chatgpt.com. When the user actively launches an AI prompt template, this script reads an extension-written local entry (lt.pending.<nonce>), fills it into the chat input, and submits it. It does not read, store, or transmit any page content, chat history, cookies, or other user data, and it makes no network requests.

Contact
